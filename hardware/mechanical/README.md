# Mechanical files

The DXF and SVG files are reference templates at nominal Hammond 1590DD
dimensions only. Connector and footswitch cutouts are intentionally absent
until `measured-components.csv` contains measurements from the supplied parts.
Print `drill-template.svg` at 100% on a 1:1 sheet, overlay the actual enclosure
and hardware, and record any change before producing metal or STEP/PDF exports.

STEP assembly and dimensioned PDF are release deliverables, not claims about
the current placeholder outline.
