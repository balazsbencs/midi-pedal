# First-article checklist

Record the board revision and operator for each item. A blank or unchecked item
blocks release.

- [ ] Unpowered visual inspection and BOM/orientation match
- [ ] Resistance-to-ground and short check on raw/protected/5V/VSYS/3V3
- [ ] Both relay contacts open before Pico/display installation
- [ ] Display VCC selector matches the measured module rating
- [ ] Pico socket, USB, SWD, and panel connector access
- [ ] Current-limited staged power-up
- [ ] USB CDC and USB-MIDI enumeration
- [ ] TRS MIDI PC/CC capture and per-message routing
- [ ] Four switches, all chords, repeat, long/double gestures
- [ ] Expression calibration, sweep, disconnect, and invalid span
- [ ] Relay open/close/toggle and reset/power-loss fail-open
- [ ] Display snapshots and dirty-update timing
- [ ] USB-only, 9 V-only, both-source, and source-removal handover
- [ ] 30-minute thermal observation
