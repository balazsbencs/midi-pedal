# License split

- `MIT.txt`: firmware, editor, protocol, tools, CI, and other software.
- `CERN-OHL-S-2.0.txt`: carrier PCB, schematics, footprints, fabrication, and
  enclosure/mechanical source.
- `CC-BY-SA-4.0.txt`: project documentation, plans, specifications, and
  validation guides.

Third-party code and documentation under `third_party/` retain their upstream
licenses. Each release manifest records the license for public artifacts.
